# 重訓重量趨勢圖

Captain 頁選中重訓動作時，`#weightTrendCard` 顯示該動作最近的重量趨勢。與 `#lastWorkout` 的版面關係由 [last-workout.md](last-workout.md) 定義。

## 資料與取樣

- 一個點代表該動作出現的一個訓練日
- y 值是當天所有組中的最高重量，不是總量
- 同日同動作即使出現多組，也只產生一個點
- 最多顯示最近 `TREND_SESSIONS = 8` 次
- 副標 `LAST n SESSIONS` 使用實際點數
- 單位沿用該動作資料，不可寫死為 kg

八個點是目前每個點都能顯示日期標籤的上限。若調整取樣數，必須同步檢查 x 軸標籤密度。

## y 軸格線

格線只標示取樣期間實際出現過的重量，避免產生器材不存在的中間刻度。

- 最低值與最高值一定保留
- 中間值由低至高加入，相鄰標籤距離小於 `GRID_MIN_GAP` 時省略
- 最多顯示 `GRID_MAX` 條格線
- y 軸映射仍在資料範圍上下保留空間，格線選值與映射留白是兩件事

## 曲線

- 使用 Catmull-Rom 轉 Bezier 的平滑曲線
- 控制點 y 值限制在每段兩端之間，避免曲線超過實際最高或最低值
- 曲線會經過器材無法設定的中間值，這是視覺平滑的取捨，不代表額外資料點

## 不做

- 不改成從 0 起算的柱狀圖
- 不改成階梯線
- 不顯示 volume 趨勢。volume 已由 PR 與 LAST WORKOUT 呈現

## 驗證

Captain 的計算函式目前未匯出成可直接執行的 metrics 測試。修改後除完整 validate 外，依 [verification.md](../verification.md) 檢查：

- y 軸標籤都來自實際重量
- x 軸日期數與取樣規則一致
- 曲線不超出資料極值
- 趨勢圖與 LAST WORKOUT 在桌機版維持預期版面
